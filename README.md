## 📌 Overview

This repository is my **central cybersecurity hub** — documenting the journey from security student to practitioner. It holds custom Python tools, security experiments, proof-of-concepts, and structured research notes across ethical hacking, malware analysis, and system defense.

> ⚠️ **Disclaimer:** All content is for **educational and ethical purposes only**. Do not use any tools or techniques on systems you do not own or lack explicit permission to test.
